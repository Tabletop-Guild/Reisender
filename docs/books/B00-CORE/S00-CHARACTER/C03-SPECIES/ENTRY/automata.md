## Advantages
### Steel Drivin' Man
Automata do not have stamina points. 

Any stamina points that the character would normally have should instead be added to their mana points. Any action that would consume stamina instead consumes mana. This grants the character a larger combined Mana and Stamina pool that can be used for either purpose.
